# 概述
这是一个用来管理个人支出的 Web 应用程序。用户可以通过可视化的仪表板了解自己的各个账户的支出情况（与预算对比）并做出相应的调整决策。

# 主要工作流程
我的 AI agent 会从银行获得我的交易流水，它会根据账户分类，智能地把每一个支出项目分类，不确定的会和我讨论，在我确认后会通过 API 或者 MCP 传到本系统 

# 主要功能

## 初始化
- 用户建立 user
- 引导用户建立首个账户
- 引导用户在账户下建立预算分类

## Dashboard 页面
- 选择账户
- 逐月汇总
- 选定月份当月分类展示 预算和实际
- 分类占比可视化

## 详细流水页面
- 用户可以查看和修改某条支出的分类

## 预算制定页面
- 按账户和分类填写预算


## AI Agent 协同
- AI Agent 可以拉取特定账户的分类
- AI Agent 可以提交符合标准分裂的支出记录
- 如果 AI Agent 提交的数据和本系统数据有重叠或冲突，可以拒绝并给出有用的反馈

## 其他
- 单用户，但支持登录鉴权
- 暂时不考虑分类调整的工作流
